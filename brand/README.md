# NevercryNow 品牌标识

| 文件 | 用途 |
|---|---|
| `mark.svg` | 主标识：渐变底 + 白色圆角块 + 终端提示符 `>_`（向 Codex 的构图靠拢）。App 图标、页头、头像都能用 |
| `wordmark.svg` | 字标：NcnsDSH + `BY NEVERCRYNOW` 副行 |
| `badge.svg` | 胶囊徽章：`MADE BY NEVERCRYNOW`，放在关于页、构建页页脚 |

规则：

- 渐变固定靛蓝 `#5B8CFF` → 薄荷 `#57E0B8`，不换色。
- 提示符笔画端点圆头，颜色用近黑 `#0B0B0F`；白色块的圆角是边长的 11%。
- 徽章只描边不填充，薄荷色小圆点在最左，字号 18、字距 3.4。
- 深色底上用白色版本；浅色底上把文字换成 `#0B0B0F`。

画布：`docs/design/brand-board.drawio`（用 drawio 打开可继续改）。
